# Models Directory

This directory contains AI models used by PrivaSee.

## DeepSeek OCR Model

The DeepSeek OCR model is required for the application to function properly.

### How to obtain the model:

1. Clone the model from Hugging Face or the official repository:
   ```bash
   cd models
   git clone <model-repository-url> deepseek-ocr
   ```

2. Or download from the official source and extract to `models/deepseek-ocr/`

### Note:
Model files are excluded from this repository due to their large size. Please download them separately before running the application.
